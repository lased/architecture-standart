**FURPS**

| Код                            | Требования                                                                                                  | Комментарий                                                                                        |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **F (Функциональные)**         |                                                                                                             |                                                                                                    |
|                                | Подача заявки на депозит через сайт с указанием ФИО и номера телефона.                                      | Базовый функционал MVP, необходим для получения первичной информации о клиенте.                    |
|                                | Звонок менеджера кол-центра после подачи заявки на сайте.                                                   | Интеграция с существующей системой кол-центра.                                                     |
|                                | Отображение списка доступных депозитов с актуальными ставками на сайте и в интернет-банке.                  | Данные о ставках должны быть доступны для клиентов.                                                |
|                                | Персонализированные ставки в интернет-банке.                                                                | Требует интеграции с системой расчета ставок (возможно, АБС).                                      |
|                                | Подача заявки на открытие депозита в интернет-банке с указанием счета и суммы.                              | Основной функционал для автоматизации процесса.                                                    |
|                                | Подтверждение операции через СМС-код в интернет-банке.                                                      | Использование существующей инфраструктуры СМС-шлюза.                                               |
|                                | Уведомление клиента о подтверждении ставки и открытии депозита по SMS.                                      | Интеграция с системой отправки SMS.                                                                |
| **U (Удобство использования)** |                                                                                                             |                                                                                                    |
|                                | Максимально удобный интерфейс для клиента на сайте и в интернет-банке.                                      | Применение принятой в компании системы дизайна.                                                    |
|                                | Быстрый отклик по всем операциям (миллисекунды).                                                            | Оптимизация запросов к базам данных, особенно при отображении справочных данных.                   |
| **R (Надёжность)**             |                                                                                                             |                                                                                                    |
|                                | Защита трафика между сайтом и интернет-банком с помощью шифрования.                                         | Использование HTTPS для защиты конфиденциальной информации.                                        |
|                                | Обеспечение доступности сервисов 24/7 и 99,9% времени.                                                      | Резервирование ЦОД, мониторинг состояния системы.                                                  |
| **P (Производительность)**     |                                                                                                             |                                                                                                    |
|                                | Оптимизация запросов к базам данных для быстрого отображения информации.                                    | Индексация часто используемых полей, кэширование данных.                                           |
|                                | Равномерное горизонтальное масштабирование и распределение запросов между серверами и ЦОД (на перспективу). | Подготовка инфраструктуры к будущему росту нагрузки.                                               |
| **S (Поддерживаемость)**       |                                                                                                             |                                                                                                    |
|                                | Разработка документации для дальнейшего расширения системы.                                                 | Описание архитектуры, API, процессов разработки.                                                   |
|                                | Использование существующих технологий и платформ разработки в банке (MS SQL, Oracle).                       | Минимизация затрат на обучение персонала и интеграцию с существующими системами.                   |
| **+R (Ограничения)**           |                                                                                                             |                                                                                                    |
|                                | Отсутствие прямой работы интернет-банка с API АБС для обработки заявок.                                     | Предотвращение перегрузки АБС и обеспечение стабильности системы.                                  |
|                                | Использование Kafka в качестве очереди сообщений (на перспективу).                                          | Подготовка к будущей интеграции с другими системами.                                               |
|                                | Несовместимость текущей платформы интернет-банка с Kafka.                                                   | Требует анализа возможности миграции или использования альтернативных решений.                     |
|                                | Вертикальное масштабирование АБС из-за базы данных Oracle.                                                  | Ограничение возможностей масштабирования АБС, необходимо учитывать при проектировании архитектуры. |
|                                | Необходимость идентификации клиента в отделении банка после подачи заявки онлайн.                           | Юридическое требование, которое нельзя обойти на данном этапе.                                     |
