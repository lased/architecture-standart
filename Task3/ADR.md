### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| **№** | **Действующие лица или системы** | **Use Case**                        | **Описание**                                                                                      |
| :---: | :------------------------------- | :---------------------------------- | :------------------------------------------------------------------------------------------------ |
|   1   | Клиент                           | Подача заявки через интернет-банк   | Клиент выбирает свой счёт и сумму, далее подтверждает операцию через СМС и создаётся заявка в АБС |
|   2   | Клиент                           | Подача заявки на депозит через сайт | Клиент оставляет свои данные, далее заявка передаётся в кол-центр                                 |
|   3   | Клиент                           | Просмотр списка депозитов           | Клиент просматривает актуальные депозиты                                                          |
|   4   | Бэк-офис                         | Подтверждение заявки в АБС          | Сотрудник бэк-офиса проверяет и подтверждает заявку, отправляя СМС клиенту.                       |
|   5   | Кол-центр                        | Обработка заявки с сайта            | Менеджер кол-центра связывается с клиентом для уточнения условий                                  |
|   6   | АБС                              | Расчёт ставок                       | Автоматический расчёт ставок на основе данных из АБС                                              |

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                                                          |
| :---: | :---------------------------------------------------------------------- |
|   1   | Горизонтальное масштабирование системы                                  |
|   2   | Шифрование данных                                                       |
|   3   | Время отклика интерфейсов < 500 мс                                      |
|   4   | Асинхронная обработка заявок через очереди событий (Kafka или RabbitMQ) |
|   5   | Доступность сервисов на 99.9% для критически важных систем (АБС)        |

### <a name="_qmphm5d6rvi3"></a>**Решение**

#### Диаграмма контекста для открытия депозитов

```mermaid
C4Context
  title Диаграмма контекста для открытия депозитов

  Person(C, Клиент, "Подача заявок")
  System(IB, "Интернет банк", "Прием и обработка заявок, подтверждение по SMS")
  System_Ext(TELEKOM, "Телеком оператор", "Отправка SMS")

  Rel(C, IB, "Подача заявки/Открытие депозита", "HTTPS")
  Rel(IB, TELEKOM, "Подача заявки", "HTTPS")
```

#### Диаграмма контейнеров для открытия депозитов

```mermaid
C4Container
  title Диаграмма контейнеров для открытия депозитов

  Person(C, Клиент, "Подача заявок")

  Rel(C, IB, "Открытие депозита", "HTTPS")
  Rel(C, S, "Подача заявки", "HTTPS")

  System_Boundary(c1, "Интернет банк") {
      Container(IB, "Интернет банк", "ASP.NET MVC 4.5 + MS SQL", "Оформление")
      Container(K, "Брокер сообщений", "Kafka", "Асинхронная обработка")

      Rel(IB, K, "Отправка заявки", "Kafka")
      Rel(K, ABC, "Передача данных")
  }

  System_Boundary(c2, "Микросервисы") {
      Container(S, "Сайт", PHP + React.js", "Предоставление и прием заявок на депозит")
      Container(SMS, "SMS шлюз", "", "Отправка сообщений клиентам")
      Container(CC, "Кол-центр", "Java + PostgreSQL", "Обработка звонков")

      Rel(S, CC, "Передача заявки", "REST API")
      Rel(CC, ABC, "Передача данных")
      Rel(SMS, C, "Отправка сообщений")
  }

  System_Boundary(c3, "Автоматизированная Банковская система") {
      Container(ABC, "Сервис АБС", "Delphi + Oracle", "Обработка запросов и ведение учета договоров")
      ContainerDb(ABCDB, "БД АБС", "SQL", "Хранение данных")

      Rel(ABC, ABCDB, "Чтение/запись данных")
      Rel(ABC, SMS, "Отправка сообщения")
  }
```

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

- Прямая интеграция интернет-банка с АБС через API
- Хранение ставок в отдельной SQL-БД

**Недостатки, ограничения, риски**

- Монолитная АБС - сложность внедрения новых функций
- Ручная обработка заявок бэк-офисом сохранена в MVP
- Legacy АБС (Delphi) - устаревшая кодовая база, высокая стоимость поддержки
